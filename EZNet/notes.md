# EZNet Reverse Engineering Notes

This folder contains reference materials from the original EZNet app that was decompiled.

## Folder Structure

- `assets/` - Images, icons, and other static assets from the original app
- `layouts/` - UI layout files and templates
- `strings/` - Text strings and localization files
- `notes.md` - This file with reverse engineering documentation

## Important Notes

⚠️ **This folder is for reference only** - Do not modify files here as they are used for understanding the original app structure.

## Key Features Identified

### Authentication
- Phone number-based OTP authentication
- JWT token management
- User profile management

### Core Features
- Event discovery and booking
- Venue management
- Review and rating system
- QR code-based entry
- Real-time notifications

### UI Components
- Modern Material Design interface
- Responsive layouts for different screen sizes
- Dark/Light theme support
- Multi-language support
